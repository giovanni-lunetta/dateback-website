Open Source Licenses

Last Updated: May 9, 2026 · DateBack v1.4.1

DateBack bundles or depends on the following open source components. Full license texts are included in the application bundle and are available below.

FFmpeg (GPL-2.0+)

DateBack ships a pre-built FFmpeg binary (ffmpeg) used to restore correct creation-date metadata on video and image files. FFmpeg is licensed under the GNU General Public License, version 2 or later (GPL-2.0+).

In accordance with the GPL, the complete corresponding source code for the exact FFmpeg binary distributed with DateBack is available at no charge:

Electron & Node.js Runtime

DateBack is built with Electron (MIT), which bundles Chromium (BSD/MIT) and Node.js (MIT). License files for these components are included inside the application bundle at DateBack.app/Contents/Resources/licenses/.

Python Runtime (PyInstaller bundle)

The memory-organizer helper binary is a frozen Python application built with PyInstaller (GPL-2.0 with the standard bootloader exception for bundled apps). The Python interpreter included in the bundle is licensed under the Python Software Foundation License (PSF).
