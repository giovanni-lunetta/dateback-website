Installation Guide

From download to running in about two minutes. Works on Mac (Apple Silicon & Intel) and Windows 10/11.

Identify your Mac chip first: Click  → About This Mac. Under Chip or Processor you’ll see Apple M1/M2/M3/M4 (Apple Silicon) or Intel Core (Intel Mac). Download the matching file in Step 1.
1

Download the right file

Open the latest GitHub release and download:

  • -arm64.dmg — Apple Silicon Mac (M1, M2, M3, M4)
  • -x64.dmg — Intel Mac (Core i5, i7, i9)
  • -x64-win.exe — Windows 10 or 11 (64-bit)
2

Open the installer

Mac: Double-click the .dmg file. A window opens with the DateBack icon and a shortcut to your Applications folder. Drag DateBack onto the Applications folder and wait for the copy to complete.

Windows: Double-click the -x64-win.exe installer. It runs silently and installs DateBack to your user account — no admin rights required. A desktop shortcut is created automatically.

3

Clear the first-launch security prompt

macOS: DateBack is Apple notarized. On first launch, macOS may show a standard message that the app was downloaded from the internet. Click Open to continue.

If macOS still blocks launch, right-click DateBack in Applications, choose Open, then click Open in the dialog. You only need to do this once.

Windows SmartScreen: Windows may show “Windows protected your PC.” Click More info → Run anyway. This is expected for new apps and disappears as the app gains download reputation.

4

Launch DateBack

Mac: Open from your Applications folder or Launchpad.

Windows: Launch from the Desktop shortcut or Start menu.

The app automatically finds your downloaded Snapchat ZIP files — no additional setup required.

✓

You’re ready

DateBack is installed. Follow the on-screen steps to select your Snapchat export ZIP and start processing your memories. Need your Snapchat data first? See the export guide →

Need help? Email support@dateback.app — we respond within 48 hours.
