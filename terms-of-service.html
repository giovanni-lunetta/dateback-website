2. Description of the Application

DateBack is a macOS and Windows desktop application that:

  • Processes and organizes Snapchat Memories exports from a downloaded ZIP file
  • Fixes file timestamps and merges media overlays locally on your device
  • Organizes processed files into dated folders on your computer
  • Optionally moves processed files into a cloud sync folder you provide (iCloud Drive, Google Drive, OneDrive, Dropbox, or Box)
